# 題目「變化題」產生規則（Variant Generation Rules）

## 目的
在**保留原題**的前提下，參考原題的**題型**與**設計目的**，產生「同考點、不同樣貌」的變化題，提升題目變化性；以 **App 呈現模式並列於原題旁**供審查。

## 名詞
- **原題（source）**：題庫題目，**不可更動**。
- **變化題（variant）**：由 AI 參照原題生成的新題（版本化）。
- **活動型別**：`choice` / `fill_blank` / `matching`。

## 設計原則（必須保留）
1. **同知識節點**（nodeId）與**同考點／設計目的**。
2. **同題型**（除非原題型明顯不適，才改並記錄原因）。
3. **難度相近**（±1 級）。
4. **年級適齡**：用語、情境、數值範圍符合該年級。
5. **答案唯一且正確**（AI 需自行驗算）。
6. 台灣小學用語、繁體中文。
7. **不逐字重製**原題敘述（改寫）；**不露出出版社名**（用適康／適翰／適南）。

## 變化維度（至少變 2 項）
- 數值／分數／單位（保持等價難度）
- 情境／人物／語境
- 問法（正問／反問）
- 選項與干擾項（似是而非，反映常見錯誤）
- 呈現形式（文字 ↔ 表格 ↔ 圖）
- 順序（選項順序、配對左右順序）

## 禁止
- 改變考點、或加入未教過的節點
- 答案不唯一、雙解、需超綱知識
- 計算／答案錯誤
- 政治、歧異、不雅內容
- 與原題完全相同（需相似度檢核）

## 輸出格式（與 appdata 相容）
```json
{ "prompt": "...", "options": ["..."], "answer": "...", "type": "choice|fill_blank",
  "rationale": "為什麼這樣變（一句話）", "figureNote": "圖形題的處理說明（可選）" }
```
儲存欄位：`sourceQuestionId, nodeId, version, payload, rationale, model, status(proposed|approved|adjust), reason, createdAt`。

## 自動品質檢查（產生後立即）
- `prompt` 非空、答案非空
- `choice`：選項 ≥ 2、選項不重複、正解存在於選項
- `fill_blank`：答案可正規化比對
- 與原題相似度 < 0.9（避免照抄）
- 未通過 → 標 `needs_review`

## 人工／AI 審查（AI 產生後由我複核）
- 逐題核對：**考點一致、答案正確、無雙解、適齡、用語**
- 標 `合格 / 需調整`（附原因）

## 批次與成本
- 以 `gemini-3.5-flash-lite` 產生，每題一次呼叫。
- **先試 20–50 題**，品質確認後再擴量。

# 圖形題方案（§ 需給方案）

原題含圖（`hasFigure` 或 `matching`）時，變化題需要新圖，四種方案：

| 方案 | 作法 | 適用 | 成本/風險 |
|---|---|---|---|
| **A. 只做文字題**（建議先做） | 圖形題**先不自動產生**，列入「圖形題待處理」清單 | 所有圖形題 | 最低；但圖形題沒變化 |
| **B. 沿用原圖＋改數字** | 圖中無數值，或數值與圖無關的題（改文字數字即可） | 少量 | 低；需人工確認圖文一致 |
| **C. 參數化重繪**（建議逐步做） | AI 產生「圖形描述／參數」→ 由 **SVG／TikZ 模板**重繪（幾何、座標、表格、長條圖最可行） | 幾何/座標/統計圖 | 中；需 figure 管線支援與模板庫 |
| **D. 人工繪圖** | AI 出題＋標「需新圖」，由美編/老師畫 | 複雜插圖（實物、情境圖） | 高；品質最好 |

**建議路線**：先 **A**（安全、先累積文字題變化），同時建 **C 的模板庫**（先支援方塊圖、數線、長條圖、座標點），B／D 為過渡。圖形題變化題一律標 `figureNote` 與 `needs_review`，未重繪前**不上線**。
